WS TOP UP - WEBSITE FILES

Upload index.html and product.html together into the ROOT of your GitHub repository.
Keep both files in the same folder.
The homepage product cards open separate product URLs, for example:
product.html?item=imo
product.html?item=starmaker
product.html?item=telegram

IMPORTANT:
1. Package prices in product.html are DEMO prices in Indian Rupees. Change them to your actual selling prices before publishing.
2. PLACE ORDER currently displays an order summary only. It does NOT collect payments, process UPI, or automatically deliver top-ups.
3. A real payment gateway / verified order workflow must be connected before accepting payments.
4. Never ask customers for passwords or OTPs.
